# SochiSiriusEventsBot

Telegram-бот для афиши Сочи и Сириуса.

## Запуск на Bothost

1. Создайте GitHub-репозиторий и загрузите эти файлы.
2. В Bothost выберите Telegram + Python.
3. Укажите Git URL репозитория.
4. Добавьте переменную окружения `BOT_TOKEN` со своим токеном BotFather.
5. Запустите бота.

Токен не хранится в коде и не должен публиковаться в GitHub.

После первого запуска тестовой версии подключаем автоматический сбор мероприятий, статусы
«ПОДТВЕРЖДЕНО / НЕ ПОДТВЕРЖДЕНО», источники и синхронизацию с Outlook.
